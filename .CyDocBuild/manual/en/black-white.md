## Make a monochrome image {#adjust}

Choose a pixel layer and open **Black & white**. Start with Neutral, High contrast, Red filter or Sepia, then adjust the mixer and tone. Original temporarily compares with the source.

## Recover the original colors {#cancel}

While the mode is open, **Cancel mode** or Escape discards the preview. **Apply** keeps it and returns to Retouch. If already applied, use **Ctrl+Z** in Retouch. If you overwrote the original file and closed the document, undo history cannot recover that file; keep a project or separate export.
