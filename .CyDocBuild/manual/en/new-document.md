## Choose a template {#templates}

1. Press **Ctrl+N**, then choose Screen, Photo or Print.
2. Select a preset, or enter Width and Height in pixels. The middle arrow swaps the dimensions.
3. Choose Transparent, White or Black. The checkerboard means transparency. Check the preview proportions.
4. Click **Create**. The canvas opens in Retouch; Ctrl+Shift+N adds a painting layer.

## Pixels and limits {#dimensions}

Every size is in **pixels**. Print presets give pixel dimensions for common paper proportions; this window does not set a physical page size or print resolution. The limit is 16,384 pixels per side and 64 million pixels total, possibly lower on your graphics device. Invalid dimensions disable Create. Reduce the size if graphics memory is insufficient.

## Keep the editable version {#save}

[Save a `.cyimg` project](doc:export#project) to retain layers, objects and masks. PNG preserves transparency; JPEG is a flattened opaque result.
