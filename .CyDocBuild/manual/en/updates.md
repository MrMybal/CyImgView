## Check and install an update {#updates}

Press **Ctrl+U**, or open Settings and choose the update check. When a version is available, the top bar shows **Update X.Y.Z**. You can install and restart, view the release, or skip that version.

The app checks automatically a few seconds after startup, at most once every 20 hours. Turn automatic checks off in Settings if you prefer manual updates. Downloads come from the project’s GitHub releases. The app returns to the same image after restarting.

Before updating, save any work as a `.cyimg` project or a separate exported image. Keep the entire **Documentation** and **plugins** folders when using a portable copy.
