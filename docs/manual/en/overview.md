## What do you want to do? {#start}

CyImgView opens images quickly and includes an editor for painting, annotations, photo adjustments and effects. This manual is installed with the app and works without an Internet connection.

- [Open your first image](doc:quickstart#open).
- [Create an empty canvas](doc:new-document#templates).
- [Add a title, frame or arrow](doc:edit#objects).
- [Understand layers and masks](doc:layers#masks).
- [Apply or cancel an effect](doc:effects#apply).
- [Recover colors after Black & White](doc:black-white#cancel).
- [Find a shortcut](doc:shortcuts#viewer).
- [Explore screenshots of each mode](doc:workspaces#gallery).

## Find your way around {#interface}

The top bar contains file and view commands. The filmstrip browses images in the same folder. **E** enters editing; **F1** opens help for the current mode. Use the annotated screenshot below to locate the main controls.

## Use this manual {#reader}

Search for a word such as “mask” or “save”. The contents panel lists sections of the current page. The language selector keeps the same page and section. Missing translations fall back to English. [Translation status](doc:translation-report#missing).

Images support zoom, dragging and keyboard controls after focus. The enlarge button stays **inside this window**; Escape reduces it. Bookmarks, private notes and reading positions stay on your device when the browser allows local storage. Export notes if storage is unavailable. [Troubleshooting](doc:troubleshooting#help).
