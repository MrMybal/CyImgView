## Choisir un modèle {#templates}

1. Appuyez sur **Ctrl+N**, puis choisissez Écran, Photo ou Impression.
2. Sélectionnez un modèle ou saisissez largeur et hauteur en pixels. La flèche centrale inverse les dimensions.
3. Choisissez Transparent, Blanc ou Noir. Le damier signifie transparence. Vérifiez les proportions de l’aperçu.
4. Cliquez sur **Créer**. La Retouche s’ouvre ; Ctrl+Maj+N ajoute un calque pour peindre.

## Pixels et limites {#dimensions}

Toutes les dimensions sont en **pixels**. Les modèles d’impression donnent des dimensions pour les proportions de papiers courants ; cette fenêtre ne règle ni la taille physique ni la résolution d’impression. La limite est de 16 384 pixels par côté et de 64 millions de pixels au total, éventuellement moins sur votre périphérique graphique. Une taille invalide désactive Créer. Réduisez la taille si la mémoire graphique est insuffisante.

## Garder une version modifiable {#save}

[Enregistrez un projet `.cyimg`](doc:export#project) pour conserver calques, objets et masques. Le PNG garde la transparence ; le JPEG donne un résultat opaque aplati.
