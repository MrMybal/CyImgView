## CyImgView 1.10.1

- Updated CyDoc reader with top-bar global search, Ctrl+K, a wider sidebar, hierarchical navigation, descriptive tooltips and preserved reading positions.
- Complete English and French manual with localized screenshots, image comparisons and diagrams. Other application interface languages open the English manual.
- Contextual F1 now opens `Documentation/Documentation.html`; the gradient tool opens its own guide.
- Public plugin API references include signatures, parameters and return values, without distributing full source listings.
- Portable ZIP and installer include the complete `Documentation/` folder. Reading remains fully offline, without a web server or additional runtime.

### Français
