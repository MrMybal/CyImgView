## CyImgView 1.10.2

- Dedicated icon for editable `.cyimg` projects: a folded document with stacked image layers, a CY monogram and the CYIMG extension label. The round application logo stays unchanged.
- Transparent Windows icon frames from 16 to 256 pixels, embedded in the executable under a stable resource ID.
- The installer registers the native project format with its own icon and opening command. Installed copies refresh this handler after automatic updates; portable copies leave installed associations alone.
- Other image associations, third-party defaults and Windows' explicit default-app choices are preserved. Uninstall removes the application's native-format registration.
- Fixed creation of installation registry keys so registration works on a fresh installation.
- Updated English/French offline manual and automated Windows icon and association checks.

### Availability and development

The published application builds are the [Windows x64 installer](https://github.com/MrMybal/CyImgView/releases/download/v1.10.2/CyImgView-1.10.2-Setup.exe) and [portable ZIP](https://github.com/MrMybal/CyImgView/releases/download/v1.10.2/CyImgView-1.10.2-win64.zip). CyImgView is in active development; no Alpha, Beta or Stable designation is established by these notes. See the [release](https://github.com/MrMybal/CyImgView/releases/tag/v1.10.2) for the published packages.

### Documented limitations

- No macOS, Linux or Windows ARM64 application build is published with this release.
- PSD/PSB viewing uses the merged image saved by its source application. PSD export rasterizes CyImgView objects and applies masks to pixels; use `.cyimg` to preserve editable project data. PNG/JPEG export is flattened.
- Several working-document formats expose an embedded preview. PDF/AI viewing shows the first page. Viewing support does not imply full-format editing or export.
- Unreal texture support excludes mobile ASTC/ETC, virtual textures, externally virtualized data and direct IoStore packages. The proprietary Oodle runtime is not distributed.
- Print templates specify pixel dimensions, not physical print size or a print-resolution setting. No AI enhancement model or service is bundled.
- Offline help needs the complete `Documentation/` directory and a browser with JavaScript. Browser restrictions on local-file storage can affect notes and reading positions.

#### Limites documentées

- Cette version ne publie pas d’application pour macOS, Linux ou Windows ARM64.
- La lecture PSD/PSB utilise l’image fusionnée enregistrée par l’application d’origine. L’export PSD convertit les objets CyImgView en pixels et y applique les masques ; utilisez `.cyimg` pour garder le projet modifiable. Les exports PNG/JPEG sont aplatis.
- Plusieurs formats de travail exposent un aperçu intégré. La lecture PDF/AI affiche la première page. La prise en charge en lecture n’implique pas une édition ou un export complets du format.
- Les textures Unreal mobiles ASTC/ETC, virtuelles, les données virtualisées externes et les paquets IoStore directs ne sont pas pris en charge. La bibliothèque propriétaire Oodle n’est pas distribuée.
- Les modèles d’impression indiquent des dimensions en pixels, sans régler le format physique ni la résolution d’impression. Aucun modèle ni service d’amélioration IA n’est fourni.
- L’aide hors ligne nécessite tout le dossier `Documentation/` et un navigateur avec JavaScript. Les restrictions du navigateur sur le stockage des fichiers locaux peuvent affecter les notes et positions de lecture.
