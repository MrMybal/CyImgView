## CyImgView 1.10.0

- Complete offline CyDoc manual with English/French guides, real screenshots, annotations, comparisons and SVG diagrams.
- Contextual F1/help buttons in the viewer and editor, including live effects, Develop, Black & White and the new-document dialog.
- Preserve shortcut help in all twelve interface languages, with explicit English fallback for untranslated detailed guides.
- Migrate decoder/editor plugin APIs, code examples and HLSL documentation; index only public SDK headers and bundled examples.
- Include the entire manual in the portable ZIP and installer. No server, CDN, Node runtime or Three.js is required to read it.
